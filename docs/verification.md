对照用户截图及实际访问的 YouTube 页面测量，已删除未确认的功能控件。坐标单位为 CSS 像素。

| 1920×1080 推荐展开侧栏 | 播放区域 x=755.25、y=64、553.5×984；标题区左移到 x=256、宽480          |

首页、观看页、推荐页分别检查 390×844、768×1024、1024×768、1440×500、1920×1080，15 组均无文档横向溢出。手机侧栏隐藏时内容从 x=0 开始。推荐页在空间不足时将标题叠在视频底部，手机评论使用底部面板。

这些是本次实际检查的视口，不代表所有浏览器、所有尺寸的逐像素保证。YouTube 存在地区及实验版本差异；没有实机检查 iOS/Safari，也没有模拟浏览器拒绝自动播放及媒体断网。代码提供播放按钮与加载失败重试作为相应回退。
