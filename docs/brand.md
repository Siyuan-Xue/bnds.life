原图为用户设计的 JPEG，2176×912，RGB 三通道，没有透明通道，白色是实际背景。图形由红、橙、绿、蓝四种品牌色组成；中间灰色暂停符号属于中性色。

透明版本的目标是仅去掉白底及图形内的白色负空间，保留四彩图形、灰色暂停符号、比例与边缘。项目素材路径为 `public/brand/logo-transparent.png`。原始文件保留不覆盖。

已保存的透明 PNG 为1937×812、RGBA，四角 Alpha=0；已在白底、深底与棋盘格底纹上检查。查看[配色与透明度预览](brand-preview.html)及[编辑记录与提示词](brand-logo-edit.md)。

用户最新确定的产品名为 **BNDS.life**。标志提供两种背景版本：`logo-transparent.png` 用于浅底，保留灰色双竖线；`logo-dark.png` 用于深底，双竖线改为白色。页头、页面标题、登录提示、示例署名和封面字标均已使用新产品名，浏览器图标也已替换。

## 四色职责

色值取自原 JPEG 各主要色块的高频 RGB 值；原图存在轻微压缩变化，因此以这些值作为统一的界面基准。

| 品牌色 | 基准色值  | 网站中的职责                                         | 使用约束                                                     |
| ------ | --------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| 蓝     | `#006ECF` | 主要操作、登录入口、文字链接、键盘焦点、导航选中图标 | 作为主要交互色。首页和推荐使用同一套选中规则                 |
| 红     | `#F22A1A` | 视频播放进度、当前播放状态的小面积强调               | 不作为整页背景或所有按钮的默认色；错误信息须有文字或图标说明 |
| 橙     | `#FF8500` | 轻量提示、需要注意的信息、小面积装饰                 | 使用浅橙底搭配深色文字；避免大面积持续强调                   |
| 绿     | `#73B338` | 成功、完成、已保存等正向反馈                         | 当前没有相应业务时不强行增加；后续保存或上传流程可沿用       |

蓝色负责“可以做什么”，红色负责“正在播放”，橙色负责“值得注意”，绿色负责“已经完成”。四种颜色各自保持稳定含义。

## 页面分配

- **页头与侧栏**：完整四彩标志配深色 BNDS.life 字标；白色背景。导航选中使用浅蓝底、蓝色图标及深色文字，两个入口保持一致。
- **首页**：封面是视觉主体。标题与作者使用中性色，悬停使用浅灰；只在交互和焦点处使用蓝色，不给每张卡片加四色边框或随机彩底。
- **观看页与推荐页**：保留黑色播放器背景，进度条使用红色，画面上叠加的控制按钮使用白色。评论链接和展开回复使用蓝色。
- **提示与状态**：浅橙提示、浅绿成功。状态必须配文字或图标，不单靠颜色区分。
- **整体比例**：白色、灰色和视频内容占主体；界面点缀以蓝色为主，其余三色按含义出现。四色组合主要留给标志。

## 配套色阶

| 用途                | 色值                  |
| ------------------- | --------------------- |
| 页面背景            | `#FFFFFF`             |
| 悬停/中性浅底       | `#F5F5F5`             |
| 正文与标题          | `#0F0F0F`             |
| 次要文字            | `#606060`             |
| 标志内灰色          | `#828691`             |
| 蓝色浅底            | `#EDF5FC`             |
| 橙色浅底 / 深色文字 | `#FFF3E6` / `#9B4A00` |
| 绿色浅底 / 深色文字 | `#F0F7E9` / `#3F711E` |
| 红色浅底 / 深色文字 | `#FFF0EE` / `#BF2115` |

橙色和绿色原色不适合直接搭配小号白字；用浅底深字，或者在原色实底上使用深色文字。红色原色优先用于图形和播放轨道，文字提示使用较深的红色色阶。蓝色原色可用于白底文字链接和白字主要按钮。

这份文档是界面配色依据。标志与产品名已接入网页，四色规则用于后续相应界面调整。
