透明版本的目标是仅去掉白底及图形内的白色负空间，保留四彩图形、灰色暂停符号、比例与边缘。项目素材路径为 `public/brand/logo-transparent.png`。原始文件保留不覆盖。

已保存的透明 PNG 为1937×812、RGBA，四角 Alpha=0；已在白底、深底与棋盘格底纹上检查。查看[配色与透明度预览](brand-preview.html)及[编辑记录与提示词](brand-logo-edit.md)。

用户最新确定的产品名为 **BNDS.life**。标志提供两种背景版本：`logo-transparent.png` 用于浅底，保留灰色双竖线；`logo-dark.png` 用于深底，双竖线改为白色。页头、页面标题、登录提示、示例署名和封面字标均已使用新产品名，浏览器图标也已替换。

## 四色职责

色值取自原 JPEG 各主要色块的高频 RGB 值；原图存在轻微压缩变化，因此以这些值作为统一的界面基准。

| 品牌色 | 基准色值  | 网站中的职责                                         | 使用约束                                                     |
| ------ | --------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| 蓝     | `#006ECF` | 主要操作、登录入口、文字链接、键盘焦点 | 作为主要交互色。首页和推荐使用同一套选中规则                 |
| 红     | `#F22A1A` | 视频播放进度、当前播放状态的小面积强调               | 不作为整页背景或所有按钮的默认色；错误信息须有文字或图标说明 |
| 橙     | `#FF8500` | 轻量提示、需要注意的信息、小面积装饰                 | 使用浅橙底搭配深色文字；避免大面积持续强调                   |
| 绿     | `#73B338` | 成功、完成、已保存等正向反馈                         | 当前没有相应业务时不强行增加；后续保存或上传流程可沿用       |

蓝色负责“可以做什么”，红色负责“正在播放”，橙色负责“值得注意”，绿色负责“已经完成”。四种颜色各自保持稳定含义。

## 页面分配

- **页头与侧栏**：完整四彩标志配深色 BNDS.life 字标；白色背景。导航未选中时使用线框图标，选中时使用用户提供的实心深色版本；选中状态没有蓝色背景，悬停仍可用浅灰。
- **首页**：封面是视觉主体。标题与作者使用中性色，悬停使用浅灰；只在交互和焦点处使用蓝色，不给每张卡片加四色边框或随机彩底。
- **观看页与推荐页**：保留黑色播放器背景，进度条使用红色，画面上叠加的控制按钮使用白色。评论链接和展开回复使用蓝色。
- **提示与状态**：浅橙提示、浅绿成功。状态必须配文字或图标，不单靠颜色区分。
- **整体比例**：白色、灰色和视频内容占主体；界面点缀以蓝色为主，其余三色按含义出现。四色组合主要留给标志。

`src/styles/globals.css` 集中定义四个原色和对应的浅底、文字色阶。登录、主要按钮、当前筛选、回复链接、键盘焦点使用品牌蓝；导航使用线框/实心图标区分状态，选中菜单使用浅蓝底；播放器进度和滑块使用品牌红；占位预览、示例评论和账户未开放提示使用浅橙底深橙字。绿色成功色阶已预留，当前没有保存或上传成功状态，不新增虚假的成功反馈。

## 方形标签页图标

用户最终指定标签页重置为**完整闭合的正方形**，不留缺口。图标沿用左侧标志的四色与双竖线：上边橙色、右边蓝色、下边绿色、左边红色，四边连续闭合；外围与内部负空间透明。浅底双竖线为灰色，深底双竖线为白色。页头仍使用完整标志及 BNDS.life 字标。

- 矢量源：`public/icon.svg`，64×64 的正方形 viewBox；深底版为 `public/brand/favicon-dark.svg`。
- ICO：`public/favicon.ico`，包含 16、32、48、64、128、256 像素六个正方形 RGBA 图层。
- 深底 ICO：`public/brand/favicon-dark.ico`，同样包含六种尺寸。
- PNG 预览：`public/brand/favicon-preview.png`、`public/brand/favicon-dark.png`，256×256。
- 页面 metadata 同时声明 ICO 尺寸和 SVG `sizes="any"`，采用新资源地址及版本参数避免继续引用缓存的横向 PNG。
- 制作方式：依据用户最终要求绘制闭合的矢量方框，再导出各尺寸 PNG 并封装为 ICO；未重新生成或改动用户的页头 Logo。深底资源通过 metadata 的媒体条件选择。

边缘检查区分两种情况：原透明 PNG 的彩色杂边属于素材问题；曲线边缘约一像素的灰色过渡属于正常抗锯齿。单独对比嵌套 SVG 和直接 SVG 没有观察到明显差异，因此不将嵌套本身认定为所有毛边的唯一原因，也不使用 crispEdges 强制关闭曲线抗锯齿。SVG 保持直接路径绘制，避免 flex 压缩。
