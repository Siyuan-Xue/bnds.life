# 账户、评论与官方故事

游客继续浏览所有已发布视频。右上角提供中文邮箱密码登录/注册，不要求邮箱验证；不新增上传、关注、点赞或账户设置。保持现有 YouTube 参考布局、两个导航项、推荐页桌面并排故事区与手机覆盖抽屉。

Better Auth 保留既有 PostgreSQL 用户、会话、密码表。增加不可由客户端写入的 isOfficial 权限，所有管理请求实时查数据库确认。普通注册昵称不能使用 official，官方账户由服务器脚本创建，邮箱由站主指定；临时密码只写入本机私有文件。

评论属于视频和用户，纯文本最长 5000 字。支持回复评论/回复，界面使用一层回复展示，父关联必须在同一视频；普通根评论分页，官方根评论放入故事区域，官方回复留在讨论中。旧视频 story 文本保留兼容。公众接口仅返回昵称、官方标识等展示信息，不返回邮箱。匿名评论与普通账户修改/删除均拒绝。请求校验来源，评论写入按账户串行限速。

官方可以修改视频名称（1–200 字）和真实拍摄日期（年/月/日精度或清空）。永久删除必须明确确认；接口隐藏视频并排队，独立低权限后台进程取得媒体锁后删除服务器原片、播放版本、封面、旧版本与同内容导入副本，再删除数据库视频及评论。界面只有在任务完成后报告已删除。任务失败保留待处理记录，允许重试。源文件哈希墓碑阻止重新导入，站主本地原片不删除。Web 进程不获得原片目录访问权。

验证使用临时数据库 schema 和人工文件，不删除实际视频。已有上传批次完成后再部署账户变更。
