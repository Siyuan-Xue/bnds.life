# bnds life Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付基于现有 T3 项目的中文公开视频浏览首版，并验证本地运行和推送 GitHub。

**Architecture:** 共用目录数据驱动首页、观看页、推荐页；独立 Shell、Player、Comments 组件。前端占位数据与未来持久化层分离。

**Tech Stack:** Next.js、TypeScript、Tailwind、tRPC、Better Auth、Drizzle、PostgreSQL、pnpm。

**Spec:** docs/superpowers/specs/2026-09-20-bnds-life-design.md

## Global Constraints

- 中文、bnds life、十一小日子；公开浏览，侧栏只有首页/推荐。
- 保留选定技术栈；不默认加入未确认功能。
- OrbStack 首次设置由用户完成；GitHub 推送不得包含密钥。

## Review Focus

- 快速切换推荐项：旧视频停止，评论对应当前项。
- 浏览器禁止自动播放：提供可用的播放操作，状态真实。
- 手机矮视口：播放器、菜单和评论关闭按钮可达，无横向溢出。
- 键盘输入评论/搜索：快捷键不能抢走输入。
- 未登录/数据库未连通：公开占位浏览不被会话查询阻断。
