# 首页、短拍与精选

按用户本次要求更新，旧的两入口共享全部视频约定由本方案取代。

## 行为

- 首页只展示时长超过 60 秒的已发布视频，沿用拍摄日期倒序的月视图。
- 短拍只展示时长不超过 60 秒的已发布视频，保留上下连续播放。保留 `/recommend` 地址兼容已有链接，导航改为「短拍」。
- 按未取整的实际媒体时长分类，60 秒整属于短拍。无效时长不进入任何分类。
- 首页顶部精选只收录首页视频；official 在视频管理中添加、移除，服务端验证身份、发布状态和时长。不自动替用户选择精选，精选不从月份列表移除。
- 搜索全部视频，使用独立搜索结果页，侧栏仍只有两个选项。短拍的直接观看链接仍有效。
- 短拍未展开故事时按实际画幅在 9:16 至 16:9 之间调整，超宽画幅保留黑边。用户随后明确：桌面展开故事时所有视频统一为 9:16，恢复原故事框宽度及等高规则；手机抽屉仍不改变背景视频。
- 手机与电脑继续使用统一的视口宽高比 1:1 分界。桌面故事框与播放器等高、上下对齐；手机故事抽屉覆盖页面，不改变背景尺寸和位置。侧栏覆盖逻辑不变。
- 保留默认有声播放、故事/评论分区、视频下线及 7 天清理规则。

## 实现与验证

1. 独立实现分类、精选字段和官方写接口；测试 59.999/60/60.001 秒边界、身份权限、下线排除、精选添加/移除。
2. 独立实现短拍宽画幅和故事布局；验证统一断点、横竖视频、桌面故事等高、手机抽屉不改变播放器。
3. 接入首页精选、月视图分类、导航、全局搜索和视频管理控件。
4. 跑单元检查，在服务器隔离 schema 中测试真实数据库和页面。生产不创建测试用户或测试视频。
5. 数据库备份后应用仅新增字段的迁移，构建并切换网页版本。上传期间保持媒体处理版本不变；同步修正本批上传验证器对首页视频范围的假设。
6. 检查线上分类和可播放状态，提交、推送并检查工作区。分别报告网站更新和上传进度。
