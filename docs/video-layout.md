# 视频宽高比适配与验收

最新调整：评论已替换为只读故事。推荐页只按视口宽高比切换桌面／手机两种播放布局：宽度不大于高度（≤1:1）使用手机版，其余使用桌面版；不再在 600px、791px 等宽度处混用不同的播放布局。剧场模式已移除，全屏保留。下文中的评论、手机底部面板与剧场描述为此前验收记录。

## 推荐页当前布局规则

- CSS 播放布局、故事对话框语义及导航菜单共用 1:1 分界。手机版隐藏常驻侧栏和上下切换按钮，故事入口叠在播放器内；横向窗口直接使用桌面布局。
- **手机版故事**：居中弹窗覆盖在原视频上，半透明遮罩；不挤压、移动或改变原视频比例。背景播放区不可操作，Tab 限制在弹窗内，Escape 或关闭按钮关闭后恢复故事入口焦点。
- **桌面版故事**：沿用右侧面板，开启时播放框使用 9:16，关闭恢复该视频比例。切换窗口布局不会替换播放器或重置当前视频、进度、暂停状态。
- 验证视口：390×844、700×950、800×800、801×800、900×700、844×390、1440×1600、1920×1080。1:1 两侧直接切换，没有原先 601–791px 的混合状态，均无横向溢出。
- 700×950 的 3:4 视频，故事开启前后播放框均为 670.5×894，位置 (14.75, 56)、滚动位置 894、暂停时间 6.050653 秒全部保持一致。跨越断点时仍停留在第二个视频，手机保留 3:4，桌面故事模式为 9:16。
- 1440×1600 竖向大窗口使用手机播放布局，菜单仍可打开导航。浏览器警告和错误日志为空。

## 用户要求与实现

1. 首页所有视频共用 16:9、12px 圆角封面，包括手机端。封面用 `cover` 填满，视频的原始比例不会改变列表行高。
2. 观看页读取 `videoWidth/videoHeight`。横屏播放器按原比例布局，最大高度为视口高度减 116px；桌面内容列同步限制宽度并居中。方形、竖屏保留标题和评论所需的列宽，画面完整居中。剧场与全屏继续完整显示画面。
3. 推荐页以 9:16 为默认框，媒体加载后在 9:16–1:1 之间适配。3:4 使用 3:4；方形或横屏使用 1:1；更窄的竖屏仍放入 9:16。打开评论后所有视频都使用 9:16，宽视频上下留黑；关闭后恢复该视频的比例。
4. 评论仅改变布局，不替换播放器 DOM，不重置播放、暂停、音量或进度。固定高度的推荐项保留滚动吸附与当前项。
5. 小屏评论使用底部面板；9:16 播放框缩放到面板上方，避免整个有效画面被面板挡住。此时面板继续接管焦点，背景控件不可操作，关闭后恢复。

尺寸来源是媒体元数据，不依赖文件名、封面尺寸或手填横竖屏字段。监听 `loadedmetadata` 和视频 `resize`；挂载时检查已缓存的元数据，避免事件在 hydration 前触发后丢失。未知尺寸先使用默认框，实际播放始终使用 `object-fit: contain`。
